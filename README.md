# Fitness Designer 🏋️🔥⚖️

一个可交互的 **体型改造方案设计师** —— 覆盖增肌 / 减脂 / 身体重组三大目标。

> 这是一个 **Reasonix Code** Skill 项目。调用后 AI 会像专业教练一样，一步步采集你的数据、分析、设计饮食和训练方案，**每步都先问你再推进**。

---

## 它能做什么

| 目标 | 说明 |
|------|------|
| 🏋️ **增肌** | 热量盈余设计 + 4-6餐蛋白质分配 + 渐进负荷训练 |
| 🔥 **减脂** | 热量缺口设计 + 保肌策略 + 力量+HIIT组合 + 平台期突破 |
| ⚖️ **身体重组** | 碳水循环 + 训练对齐 + 预期管理（重组最慢，提前告知） |

### 技能模块

| 模块 | 内容 |
|------|------|
| **Phase 0** | 采集用户数据（性别/年龄/身高/体重/体脂/运动经验/健康） |
| **Phase 1** | 知识框架 + BMR/TDEE计算 + 补剂真伪辨别（含证据等级） + 6种饮食法对比 |
| **Phase 2** | 食物替换表（蛋白质/碳水/脂肪）+ 三套独立饮食模板 + 生活场景指南（喝酒/聚餐/旅行/素食） |
| **Phase 3** | 热身+Deload规则 + 增肌/减脂/重组各独立训练方案 + 替代动作库 + HIIT方案库 |
| **Phase 4** | 补剂用法 + 睡眠/压力/NEAT恢复管理 + 每周监控体系 + 调整信号 + 反向饮食过渡 + 换目标信号 |

### 亮点功能

- ✅ **安全边界** —— 热量低于阈值自动警告，异常信号建议就医
- ✅ **反向饮食（Reverse Dieting）** —— 减脂结束后的逐周过渡计划，防反弹
- ✅ **6种饮食法对比** —— 均衡 / 间歇断食 / 碳水循环 / 低脂 / 低碳 / 生酮，让用户选而非你替选
- ✅ **生活场景指南** —— 喝酒怎么喝、火锅怎么点、出差怎么办、素食者怎么吃够蛋白
- ✅ **4种HIIT方案** —— 轮换刺激，避免适应
- ✅ **替代动作库** —— 引体做不了→高位下拉，深蹲不舒服→高脚杯深蹲
- ✅ **女性差异化调整** —— 周期波动预警、最低脂肪≥1.0g/kg、铁需求
- ✅ **训练减载周（Deload）** —— 每4-6周自动安排恢复周
- ✅ **科学引用** —— 关键参数标注ISSN/ACSM/NSCA来源，补剂标注A-D证据等级

## 设计哲学

1. **每步确认** —— 不一口气倒完全部内容，用户点头才推进
2. **数据驱动** —— 每个数字基于用户体重×系数计算，不说"多吃蛋白"而说"你的170g=鸡胸肉720g"
3. **诚实科普** —— 补剂标注证据等级，是A级还是D级（智商税）说清楚
4. **灵活替代** —— 每种食物和动作都有 Plan B
5. **安全第一** —— 热量阈值警告、速度过快要停、异常信号建议就医
6. **可持续优于激进** —— 能坚持8周的计划 > 2周就放弃的完美计划

## 科学依据

本指南中的宏量营养素范围参考以下机构立场声明：

| 机构 | 引用内容 |
|------|---------|
| **ISSN**（国际运动营养学会） | 蛋白质1.6-2.2g/kg、肌酸立场声明、补剂评估 |
| **ACSM**（美国运动医学会） | 运动营养指南、热量缺口建议 |
| **NSCA**（美国国家体能协会） | 训练周期化、渐进负荷指南 |
| **Mifflin-St Jeor (1990)** | BMR计算公式（当前最准确通用公式 ±10%） |

补剂证据等级说明：

| 等级 | 定义 |
|------|------|
| **A级** | 多个双盲RCT + 荟萃分析支持 |
| **B级** | 有限RCT或队列研究支持 |
| **C级** | 少数小样本研究或间接证据 |
| **D级** | 无证据或证据证明无效 |
